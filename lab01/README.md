## variant.py — вариант 7: «Магазин электроники»

Позиции: «Кабели» и «Адаптеры».

### Пример заказа

- Название заказа: `Магазин электроники`
- Заказчик: `Иванов И.И.`
- Позиция 1: Кабели, количество 5, цена за единицу 250.50 руб.
- Позиция 2: Адаптеры, количество 3, цена за единицу 499.99 руб.
- Доставка: 150.00 руб.
- Внесённая сумма: 3000.00 руб.

### Расчёт вручную

- Стоимость кабелей: 5 × 250.50 = 1252.50
- Стоимость адаптеров: 3 × 499.99 = 1499.97
- Стоимость товаров без доставки: 1252.50 + 1499.97 = 2752.47
- Итого с доставкой: 2752.47 + 150.00 = 2902.47
- Общее количество единиц: 5 + 3 = 8
- Сдача: 3000.00 − 2902.47 = 97.53

### Ожидаемый вывод программы

```

Заказчик: Иванов И.И.
Кабели | 5 | 250.50 | 1252.50
Адаптеры | 3 | 499.99 | 1499.97
Стоимость товаров без доставки: 2752.47
Стоимость доставки: 150.00
Итого с доставкой: 2902.47
Общее количество единиц: 8
Сдача: 97.53
```
